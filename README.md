# Cryptoclinic Pay

**Bitcoin Payment + Tax Compliance System**

Official mobile app by **Unitum Holdings Corporation** — the Bitcoin franchise.

## Features
- Accept BTC (Lightning & On-chain) via Breez SDK
- Real-time FMV conversion (USD/NGN)
- US IRS compliance: FMV logging, sales tax, export for 8949/1099-DA
- Nigeria FIRS compliance: Peppol BIS 3.0 e-invoices, MBS clearance, QR/CSID/IRN
- Offline-first with sync
- Dual-country mode
- Integrations: QuickBooks, Xero, POS

## Tech Stack
- Flutter (iOS & Android)
- Breez SDK for Lightning
- TaxJar/Avalara for US tax
- Custom UBL generator for Peppol

## Getting Started
1. Clone repo
2. flutter pub get
3. Run on iOS/Android

**Note:** For production, obtain FIRS Access Point accreditation and US money transmitter licenses.

Full blueprint in docs/ (coming soon).

- Complies with Apple/Google crypto policies (wallets allowed with licensing)
